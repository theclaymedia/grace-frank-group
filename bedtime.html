How it works

One story,
every week

Each episode runs about five minutes, which is long enough for a proper story and short enough to finish before anyone falls asleep halfway through.

Episodes follow one character at a time. Season One opens with ten Truly the Turtle stories, then Gracie, then Hope, so a child can stay in one world for a while before the next one opens up.

Every episode carries one idea: trust, kindness, courage, making amends. There is a short parent card with each one if you would like something to talk about afterwards.
